# Анализ транзакций игорной платформы с использованием машинного обучения

Проект содержит программную реализацию вычислительного эксперимента для дипломной работы по теме совершенствования системы безналичных расчётов с использованием криптовалют в игорном бизнесе Республики Беларусь.

Скрипт `chapter4_experiment_revised.py` формирует модельный анонимизированный набор транзакций, обучает модели машинного обучения, оценивает качество классификации операций для ручной проверки, рассчитывает экономические издержки ошибок, моделирует очередь ручного контроля и прогнозирует дневной транзакционный поток.

## Что делает программа

1. Генерирует модельный анонимизированный датасет транзакций.
2. Формирует признаки операций: сумма, канал оплаты, тип операции, время, задержка, KYC-score, предыдущие отказы и другие параметры.
3. Делит данные по времени на обучающую, валидационную и тестовую выборки.
4. Обучает модели машинного обучения:

   * Logistic Regression;
   * Logistic Regression + SMOTE;
   * Random Forest;
   * Gradient Boosting.
5. Оценивает модели по метрикам:

   * ROC-AUC;
   * PR-AUC;
   * accuracy;
   * precision;
   * recall;
   * F1-score;
   * F2-score.
6. Подбирает порог классификации на валидационной выборке.
7. Рассчитывает издержки FP/FN-ошибок.
8. Оценивает очередь ручной проверки по модели M/M/c.
9. Строит прогноз дневного количества транзакций.
10. Сохраняет таблицы, графики и JSON-отчёт с результатами.

## Установка и запуск

Рекомендуется использовать Python 3.10 или выше.

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение на Windows:

```bash
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install pandas numpy matplotlib scikit-learn imbalanced-learn
```

Запустить программу:

```bash
python code.py
```

## Результаты работы

После запуска создаётся папка:

```text
chapter4_artifacts
```

В неё сохраняются:

* `transactions_anonymized_model.csv` — модельный анонимизированный журнал транзакций;
* `model_metrics.csv` — метрики качества моделей;
* `timeseries_cv_scores.csv` — результаты проверки TimeSeriesSplit;
* `validation_thresholds.csv` — выбранные пороги классификации;
* `threshold_sensitivity.csv` — чувствительность метрик к порогу;
* `cost_threshold.csv` — экономические издержки FP/FN-ошибок;
* `queue_analysis.csv` — расчёт очереди ручного контроля;
* `daily_forecast.csv` — прогноз дневного транзакционного потока;
* `experiment_report.json` — краткий итоговый отчёт;
* PNG-графики для визуализации результатов.

## Основная идея

Модель позволяет оценивать вероятность того, что транзакция должна быть направлена в ручную проверку. Это помогает связать машинное обучение, экономику ошибок и системный анализ нагрузки на персонал.

Проект демонстрирует, как алгоритмический модуль может быть встроен в целевую платёжную модель для автоматизированного анализа транзакций, оценки рисков и планирования ручного контроля.
